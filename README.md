# Saree Rental Web Application - UTSAV-VASTHRA

## 📌 Project Overview
This is a **web development application** designed for **renting sarees for grand events** such as weddings, receptions, and festivals.  
The platform aims to provide users with an easy way to explore, select, and rent premium sarees online.

The project includes both **frontend and backend development** and is currently **under active development**.


## 🎯 Objectives
- To build an event-focused saree rental platform  
- To provide a smooth and responsive user experience  
- To support scalable backend integration for inventory and user management  


## 🧩 Features (Planned & In Progress)
- User-friendly homepage with featured sarees  
- Saree listing and detailed view sections  
- User authentication (login/signup)  
- Customer reviews section  
- Informational sections explaining how the platform works  
- Backend integration for database and APIs
